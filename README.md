# Instagram Engagement Diagnosis

A data-driven analysis project to investigate the decline in reach and engagement on Instagram.  
Using text embeddings, unsupervised machine learning, and explainable AI models for semantic interpretation, this project identifies patterns in content performance and provides insight into engagement trends.

**Key techniques:** NLP embeddings, clustering, time-series analysis, Looker Studio dashboards, open-source LLM explainability.
